# Status paper: Constructor resilience and the Ikonic FREE path

**Date:** 2026-08-18  
**Audience:** founders / agents continuing voice, terminal, and coherence work  
**Repos:** https://github.com/rivletio/constructor-resilience · Ikonic branch `feat/constructor-fastpath`

---

## Abstract

We have two related tracks. **Constructor-resilience** is an open method for durable claims (*atoms*), consistency graphs, resilient *packets*, mint/critique/review, and query eval—now a public package with a local MLX default (Qwen3-8B). **Ikonic** already runs a native voice/text FREE ladder (patterns, working sets, utterance cache, terminal DSL) with residual LLM as fallthrough. The joint thesis is that packets become **Knowledge FREE**—a mid-ladder tier—while the **terminal bash-like DSL and NL→CLI maps remain mandatory Verb FREE**. Personal vault topics alone are not enough for a product fast path; packets must **ship inside subsystem packages** (same doctrine as `utterance_seed.yaml`) so every install that enables a subsystem shares that floor. Mint and critique stay offline. The turn only loads and speaks (or falls through).

## 2. Architectural law (locked)

### Verb FREE vs Knowledge FREE

| | Verb FREE | Knowledge FREE |
|--|-----------|----------------|
| **Question** | What should we *run*? | What do we *believe* / explain? |
| **Artifact** | Terminal DSL, registry, pipes; utterance seeds; curated maps; session YAML | Atoms + packets |
| **Shared floor** | Package YAML seeds (`utterance_seed`, `voice_session`, …) | Package `coherence/topics/*` (proposed) |
| **Execute** | `/discover`, `/open`, actions | Speak claims; optional “try `/cmd`” suggestion |
| **Non-negotiable?** | **Yes** | Additive; must not absorb the command layer |

**Law:** The fast path *executes* through terminal (and peer FREE actions). Packets may explain, gate residual, or suggest a command. They do not become the command layer.

### Subsystem-shipped packets

Personal research topics are insufficient for product FREE. Each subsystem should ship:

```text
subsystems/<id>/coherence/topics/<id>-law/{atoms.json,packet.json}
```

Materialize into `{vault}/coherence/` on enable/update—**package builtin → vault overlay → user teach**—identical to utterance seed load order. Everyone who installed that subsystem shares that floor; user mint overlays; package atoms move by release.
